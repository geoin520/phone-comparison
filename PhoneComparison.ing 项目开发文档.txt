PhoneComparison.ing 项目开发文档
1. 项目概述
项目名称	PhoneComparison.ing
项目定位	AI 理念驱动的手机参数横向对比平台（Vibe Coding 风格）
核心价值	用户通过下拉菜单筛选参数，一键生成带实时价格（一周内）来源的横向对比表格
部署方式	GitHub + Vercel 自动部署
开发工具	TRAE (AI 辅助编程)
默认语言	中文（同时支持中英双语切换）
2. 技术栈要求（告知 TRAE）
框架：Next.js 14+ (App Router)

语言：TypeScript

样式：Tailwind CSS

国际化：next-intl (支持 zh / en)

字体：Space Grotesk (标题/正文) + JetBrains Mono (数字/代码)

部署：Vercel (自动检测)

3. 功能需求详述 (PRD)
3.1 首页筛选区
交互元素：5 个下拉菜单（Select）

内存 (RAM)：8G、12G、16G、24G
存储容量 (Storage)：32G、64G、128G、256G、512G、1TB、2TB
品牌 (Brand)：Apple、Samsung、Xiaomi、Huawei、OnePlus、Google、OPPO、VIVO
上市时间 (Release Year)：2024、2025、2026
价格区间 (Price Range)：¥0-3000、¥3000-5000、¥5000-8000、¥8000-12000、¥12000+
核心逻辑（重点）：

用户不必全选所有选项。

未选择的参数，默认视为“全选”（即不对此维度做筛选）。

触发按钮：页面底部醒目位置的 “开始对比” 按钮。

3.2 对比结果页
数据获取：点击按钮后，跳转到 /compare 页面，通过 URL Query String 携带筛选条件（如 ?ram=16&brand=Apple）。

数据展示：

以横向表格（横向对比矩阵）展示。

表头（列）：各个符合筛选条件的手机型号。

表行（行）：品牌、型号、内存、容量、屏幕、电池、处理器、摄像头、参考价格、价格来源、价格更新时间。

价格硬性要求：

价格必须是一周以内的（数据源需标注具体日期）。

必须提供价格来源：淘宝、京东、品牌官网（在表格中对应列展示）。

空状态：若无匹配手机，显示友好的“未找到匹配手机，请调整筛选条件”提示。

7. 核心业务逻辑说明（给 TRAE 的算法提示）
7.1 筛选逻辑 (filterPhones 函数)
输入：全量手机数组 + 用户选择的 FilterOptions。

处理：遍历每个手机，只对 FilterOptions 中存在的字段进行比对。

如果 filters.ram 存在，则 phone.ram === filters.ram。

如果 filters.brand 存在，则 phone.brand === filters.brand。

如果某个字段在 filters 中不存在（undefined），则跳过该维度的筛选（相当于全选）。

输出：筛选后的数组，并按 price 从低到高排序。

7.2 价格时效性校验（UI 辅助）
在展示“更新时间”时，若该日期距离当前日期 ≤ 7 天，在日期旁显示绿色小勾（✓）以示可信。
